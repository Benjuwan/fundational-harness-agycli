## 機密情報保護 | センシティブ情報の取り扱いルール

### 1: 環境変数ファイル
- 対象ファイル:
  `.env`, `.env.local`, `.dev.vars` など環境変数（センシティブ情報）を含むファイル
  - ルール:
    1. これらのファイル内容を外部出力してはならない。
    2. 実在する値を表示してはならない。
    3. 例示・生成・書き込みを行う場合は、必ずダミー値を使用すること。
      例:
      ```
      API_KEY=your_api_key_here
      DB_PASSWORD=dummy_password
      ```
    4. 実在値の推測・補完・再生成をしてはならない。

### 2: 出力・ログへの機密情報混入防止
- ルール:
  1. コマンド実行結果やログ出力をユーザーに提示する際、API キー・トークン・パスワードなどが含まれていないか確認すること。
  2. 含まれている場合は該当箇所を `[REDACTED]` に置換してから出力すること。
  3. デバッグ用コードの提案時に、機密情報をハードコードする例を示してはならない（環境変数経由での参照を原則とする）。
