# 汎用ハーネス
本ディレクトリ (`fundational-harness-agycli`) は、一般ビジネスユーザー（ナレッジワーカー）が日常業務でAIエージェントを安全かつ効率的に活用するための「汎用的なルール・スキル・サブエージェント」のセット（ハーネス）を提供します。

## プロジェクトローカル構成とプラグイン構成の違い
本ハーネスは、利用する環境に合わせて2つの形式で導入することができます。

### 1. プロジェクトローカル構成 (`.agents/` ディレクトリ配置)
プロジェクト固有の制約やルールが強い場合に使用します。
プロジェクトのルートディレクトリに `.agents/` フォルダを配置することで、そのプロジェクト内でのみハーネスの設定が有効になります。
- **メリット**: プロジェクトごとの細かなカスタマイズが容易。特定のリポジトリ専用のルールを安全に適用可能。
- **デメリット**: 他のプロジェクトでは設定を引き継げない。

### 2. グローバル（プラグイン）構成 (`~/.gemini/config/plugins/` 等への配置)
複数のプロジェクトや、特定のディレクトリに依存しない汎用的なタスク実行（リサーチ、資料作成、レビューなど）において、一貫したAIの挙動を保証したい場合に使用します。
設定をプラグイン化してAIに読み込ませることで、どのディレクトリで作業していてもこのハーネスが有効になります。
- **メリット**: 環境を横断して、常に同じルール・スキル・品質でAIを活用できる。
- **デメリット**: プロジェクトごとの極端な個別事情には対応しづらい場合がある。

## 用途と使い方

この汎用ハーネスには、ナレッジワーカー向けに抽象化された以下の要素が含まれています。

- **ルール (`rules/`)**: 安全な運用（破壊的操作の防止や事前承認）、過剰推論の抑制、品質ガイドラインなど、AIが暴走せず堅実な仕事をするための行動規範。
- **スキル (`skills/`)**: 情報収集（リサーチ）、文書レビュー、プレゼン資料作成など、ビジネスの現場で頻出するタスクを効率化する専用スクリプト群。
- **サブエージェント (`agents/`)**: タスクをフェーズごとに分業し、AI自身の「確証バイアス」を防ぎながら多重レビューで品質を担保する専門エージェント群（QAオーディター、タスク実行者など）。

これらの設定が読み込まれることで、AIエージェントは単なるチャットボットから、「信頼できるビジネスパートナー（自律型ワーカー）」へと昇華します。
